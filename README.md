# Inventory and Order Management System

A program that helps a small store keep track of its products, stock, and customer orders.

## About the Project

A small store needs to know what products it has, how many units are available, and which customers ordered what. This system does that work.

The system will:

- Keep a product list and track stock (the number of units available for sale).
- Save supplier and customer details.
- Record new stock arriving at the store.
- Create customer orders with one or more products.
- Confirm an order only when enough stock is available.
- Cancel an order and return its stock without counting it twice.
- Show sales reports, low-stock reports, and a history of stock changes.
- Provide a login and simple web pages for the store operator.

The project uses one store, one operator account, one currency, whole-number quantities, and practice data. It runs on your own computer.
